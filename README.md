### [Крестики Нолики Хаос](https://github.com/laubakhmilena/tic-tac-toe-chaos)

Адаптивная браузерная игра в крестики-нолики с четырьмя игровыми режимами: классическим, стратегическим, бесконечным и режимом с исчезающими знаками. В проекте также реализованы облачные сохранения, ежедневные задания, система дружбы с питомцем, угощения, сундуки, разные настроения Кошечки и мини-игра «Пятнашки».
